# ДЗ 9. Merge Two Sorted Lists

Итеративное решение задачи [LeetCode 21](https://leetcode.com/problems/merge-two-sorted-lists/) на PHP 8.1+.

Алгоритм переиспользует узлы исходных списков и на каждом шаге присоединяет меньший текущий элемент. Время — `O(n + m)`, дополнительная память — `O(1)`.

## Запуск

```bash
php tests/run.php
```
